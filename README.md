# Interview Path

Interview Path 是一個可直接開始的全端工程師面試練習網站。首批題庫有 42 題，涵蓋 JavaScript／TypeScript、React、瀏覽器與網路、後端與 API、SQL 與資料庫、系統設計和工程實務。

## 練習方式

1. 用關鍵字、主題、題型或練習狀態找題目。每題都能寫自己的回答和筆記。單選題和多選題也能檢查答案。
2. 展開參考解答，對照答題重點和常見追問。勾選「預設展開」即可讓後續題目的詳解預先打開。
3. 將題目標成未開始、待複習或已練熟。到「練習路線」看各主題進度，或開啟「我的筆記」回顧已寫過的內容。

## 備份與還原

回答、筆記、選擇題作答、進度與顯示設定儲存在此網站的瀏覽器 localStorage。從「資料備份」匯出 JSON，就可以到另一台裝置匯入。匯入會保留雙方各自有內容的欄位，遇到同一欄位有不同內容時，可選擇優先保留哪一份。備份也會帶入解答顯示設定與最後練習的題目。

## 開發

需要 Bun。使用原生 HTML、CSS 和 TypeScript，建置結果為可部署在靜態主機的網站。

    bun run dev
    bun test
    bun run build

開發預覽預設在 http://127.0.0.1:4173，部署輸出在 dist/。在 src/questions.ts 增加題目並給它固定且唯一的 ID。既有 ID 會對應本機備份中的題目紀錄，更新題幹時請保留該 ID。

題庫以 [ExplainThis 的主題式瀏覽](https://www.explainthis.io/zh-hant/swe-questions/frontend) 為參考，使用獨立撰寫的情境題、參考解答與追問。
